## Chi tiết Bài nộp: Bài 1 lesson 1

- **Đề tài:** Phân biệt cơ chế vận hành của LLM truyền thống và AI Agent tại FPT Telecom.
- **Nội dung hoàn thành:**
  1. *Nhiệm vụ 1:* Bóc tách cơ chế kỹ thuật cốt lõi giữa chuỗi đóng LLM (`Input -> Reasoning -> Output`) và vòng lặp nhận thức tự chủ AI Agent (`Input -> Sense -> Plan -> Tool Calling -> Environment Feedback -> Output`).
  2. *Nhiệm vụ 2:* Phân tích quy trình xử lý ca thực tế 5 bước (Đo kiểm tín hiệu NMS và nâng cấp gói cước qua Billing).
  3. *Nhiệm vụ 3:* Đánh giá hiệu quả vận hành (Giảm tải 26.500 yêu cầu/ngày cho tổng đài viên, tương đương 67.95%) và 02 thách thức kỹ thuật lớn nhất.
- **Dung lượng bài viết:** 571 từ (Chuẩn yêu cầu 450 – 600 từ).
